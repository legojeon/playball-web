아이폰에 플레이 볼! 설치하기

  1. 이 게임을 Safari에서 여세요. 다른 앱 안에서 링크를 열었다면 Safari로 이동하세요.
  2. 이 안내 맨 아래의 ‘게임으로 돌아가기’ 버튼을 눌러 게임 메인 화면으로 이동하세요.
  3. 게임 메인 화면에서 Safari의 공유 → 홈 화면에 추가를 누르세요. ‘웹 앱으로 열기’가 표시되면 켜고 추가하세요.
  4. 홈 화면의 플레이 볼! 아이콘으로 게임을 여세요.
  5. 인터넷에 연결된 상태에서 게임의 설정(☰) → 오프라인 준비 완료를 확인하세요.
  6. 개인 응원가는 홈 화면 앱 안에서 추가하세요. 음악이 없어도 게임을 즐길 수 있어요.

Safari에서 저장한 기록이나 음악이 홈 화면 앱으로 옮겨지지 않을 수 있어요. 앱 안에서 초기 저장을 마친 뒤에는 인터넷 없이도 플레이할 수 있습니다.

처음 화면을 터치하면 소리가 시작됩니다. 기록과 음악은 기기에만 저장되며, 데이터 삭제나 저장 공간 정리로 사라질 수 있습니다. 응원가 원본은 따로 보관해 주세요.

업데이트를 받으려면 인터넷에 연결해 게임을 다시 여세요. 경기 중 ‘새 버전으로 다시 시작’ 버튼이 표시되면 편한 때 눌러 주세요.

아래 버튼으로 게임 화면에 돌아간 뒤, Safari의 공유 → 홈 화면에 추가를 눌러 설치하세요.
